# Food Delivery App – UI/UX Design

## Project Overview
A user-centered UI/UX design for a food delivery mobile application created using Figma. The design focuses on intuitive navigation, visually appealing interfaces, and a seamless food-ordering experience.

## Tools Used
- Figma
- UI/UX Design Principles
- Wireframing & Prototyping

## Key Features
- User-friendly home screen
- Food discovery and browsing
- Restaurant and food item selection
- Cart and ordering flow
- Clean and intuitive navigation

## Design Goals
- Improve usability and user experience
- Maintain visual consistency
- Simplify the food ordering journey
- Create an attractive and intuitive interface
